# 💰 Multi-Currency Personal Budget Tracker

A responsive, multi-currency personal finance web application engineered with **React**, **TypeScript**, and **Tailwind CSS**, integrated with **Firebase** services for secure cloud state and local storage fallback.

---

## 🚀 Key Features

- **Multi-Currency Planning:** Real-time multi-currency support tailored for cross-border financial tracking.
- **Planner Engine:** Dynamic 31-day and 12-month budget projection models.
- **Data Persistence:** Hybrid architecture combining Firestore cloud synchronization with offline-ready local storage.
- **Export & Reporting:** Client-side generation of financial summaries and PDF export capabilities.
- **Localization (i18n):** Multi-language interface supporting Ukrainian (УКР) and English (EN).
- **Security & Data Integrity:** Configured Firestore security rules and compound indexes for performant querying.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, PostCSS
- **Backend / BaaS:** Firebase (Firestore, Firebase Hosting / Rules)
- **Tooling:** npm, Git, ESLint
