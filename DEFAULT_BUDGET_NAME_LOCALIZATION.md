# 🌍 Локалізація дефолтної назви бюджету

## 🎯 Мета
Зробити дефолтну назву бюджету ("Main"/"Основний") залежною від мови користувача при створенні першого бюджету.

## ✅ Що було зроблено

### 1. 📝 Додано нові переклади

**Українська (`src/i18n/locales/uk.json`):**
```json
"budget": {
  "main": "Основний",
  "defaultBudgetName": "Основний",  // ← НОВЕ
  ...
}
```

**Англійська (`src/i18n/locales/en.json`):**
```json
"budget": {
  "main": "Main",
  "defaultBudgetName": "Main",  // ← НОВЕ
  ...
}
```

### 2. 🔧 Оновлені файли

#### `src/utils/storageHelpers.ts`

**Було:**
```typescript
export const createEmptyDefaultBudget = (): Budgets => {
  return {
    'default': {
      name: 'Основний',  // ❌ Хардкод
      ...
    }
  };
};
```

**Стало:**
```typescript
import { translate } from '../i18n/config';

export const createEmptyDefaultBudget = (): Budgets => {
  return {
    'default': {
      name: translate('budget.defaultBudgetName'),  // ✅ З локалізації
      ...
    }
  };
};
```

#### `src/hooks/useFirestoreSync.ts`

**Було:**
```typescript
const budgetName = translate('budget.main');
```

**Стало:**
```typescript
const budgetName = translate('budget.defaultBudgetName');
```

#### `src/hooks/useBudgetSettings.ts`

Два місця де створюються fallback бюджети:

**Було:**
```typescript
name: translate('budget.main')
```

**Стало:**
```typescript
name: translate('budget.defaultBudgetName')
```

---

## 🔑 Різниця між ключами

### `budget.main`
- **Використання:** Fallback значення для вже існуючих бюджетів
- **Приклади:**
  - Відображення назви бюджету
  - Fallback при імпорті файлу без назви
  - Fallback коли назва бюджету відсутня

### `budget.defaultBudgetName`
- **Використання:** Створення НОВИХ дефолтних бюджетів
- **Приклади:**
  - Перший запуск додатку
  - Вхід в новий акаунт Google
  - Створення пустого бюджету після очищення

## 🎬 Сценарії використання

### Сценарій 1: Перший запуск (анонімний користувач)

**Українська мова:**
```
Користувач відкриває додаток → Створюється бюджет "Основний"
```

**Англійська мова:**
```
User opens app → Budget "Main" is created
```

### Сценарій 2: Вхід в новий Google акаунт

**Крок 1:** Користувач має українську мову в браузері
```
Вхід в акаунт → Синхронізація → Бюджет "Основний"
```

**Крок 2:** Користувач змінює мову на англійську
```
Змінює мову → Назва залишається "Основний" (вже створено)
```

### Сценарій 3: Новий користувач з англійською мовою

**Крок 1:** Користувач має англійську мову
```
Перший запуск → Бюджет "Main"
```

**Крок 2:** Вхід в Google акаунт
```
Синхронізація → Бюджет "Main" зберігається
```

## ✨ Результат

Тепер дефолтна назва бюджету **динамічно залежить від мови користувача** при створенні:

| Мова користувача | Назва першого бюджету |
|------------------|----------------------|
| 🇺🇦 Українська | "Основний" |
| 🇬🇧 Англійська | "Main" |

**Важливо:**
- ✅ Назва встановлюється **при створенні** бюджету
- ✅ Після створення назва **не змінюється** автоматично при зміні мови
- ✅ Користувач може **вручну перейменувати** бюджет в будь-який момент
- ✅ При імпорті файлу назва береться **з файлу**, а не з мови

---

## 🎉 Висновок

Тепер користувачі бачать назву першого бюджету **своєю мовою** з моменту створення, що покращує UX та робить додаток більш інтуїтивним для міжнародної аудиторії!
